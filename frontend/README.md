# SmartAttend Frontend

Next.js + TypeScript client for SmartAttend.

Current MVP:
- Basic attendance verification page.
- API helper for the FastAPI backend.
- Environment-based API URL.

Planned modules:
- authentication and role-aware navigation
- lecturer session management
- rotating QR-code display
- student attendance verification
- attendance history and reporting
- reusable accessible UI components

The browser is not a trust boundary: authentication, enrolment and attendance decisions remain server-side.
